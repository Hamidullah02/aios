# Module Document Template

## Purpose

This document is the template for the module documents.
Each module folder has the same six documents. The
documents use the same section layout. The template
shows the layout. The writer replaces the placeholder
text with the module content.

The template applies the ASD-STE100 writing standard. The
writer must follow the standard for all prose. See
`docs/standards/STE-STYLE-GUIDE.md`.

## Section Order

The six documents have the section order below. The
writer keeps the section order. The writer removes a
section only when the section is not applicable and the
writer states the reason for the removal.
